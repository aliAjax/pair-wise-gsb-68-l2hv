# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 原始证据、二次来源、待证信息分类与内容哈希留档。
- 证据关系图、来源时间线、多人批注和解决状态。
- 发布前校验、版本记录、完整档案与审计导出。
- 来源升版或撤回级联：未发布结论自动失效重算，已发布版本冻结留档并另开复核批次。
- 编辑批次提交：同一批次并发提交先到者生效，晚到者保留冲突值待复核。
- 写入失败从最后一个完整批次恢复，失败批次可重试；旧数据升级时无来源链的主张转入待核，不能直接发布。

端口为`18468`。

```bash
npm install
npm run build
npm run dev
npm run verify   # 验证级联、并发、恢复与迁移规则
```
