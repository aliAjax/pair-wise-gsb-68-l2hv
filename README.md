# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 原始证据、二次来源、待证信息分类与内容哈希留档。
- 证据关系图、来源时间线、多人批注和解决状态。
- 发布前校验、版本记录、完整档案与审计导出。

## 主张—证据—版本—审计联动规则

- **来源升版/撤回级联**：来源以公开地址为身份登记版本。来源一改动，引用它的未发布主张结论立即失效待重算；已发布版本冻结原样不回写，系统另开复核批次，复核批次生效后主张转回复核流程。
- **批次并发**：变更以批次提交，批次携带日志序号基线。两个窗口同时提交同一批次时只有先到的生效；晚到批次转为冲突待复核，保留冲突值，可选择保留当前值或采用冲突值重新提交。
- **写入恢复**：每个批次先写日志再落状态，完整批次带校验和与快照。写入中断后从最后一个完整批次恢复，失败批次重置为待提交重试。批次中心提供故障注入开关用于演练。
- **旧数据迁移**：存储版本自动升级；没有来源链的主张先进入「待核」，补齐来源链并完成核验前不能直接发布。

